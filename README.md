# AgroControl

Sistema de Gestión de Agroquímicos AgroControl.

## Módulo

Gestión de productos agroquímicos.

## Stack tecnológico

Python + Flask.

## Flujo de ramas

- `main`: rama principal y estable del proyecto.
- `feature/gestion-productos`: rama destinada al desarrollo del módulo de gestión de productos agroquímicos.
- Los cambios se desarrollan en ramas `feature`.
- Los cambios terminados se integran a `main` mediante Pull Request.
- Antes de integrar los cambios se verifica que el pipeline de integración continua se ejecute correctamente.
